Next.js 프로젝트 React 교육 내용 포함 여부 보고
===============================================

분석 범위: frontend\nextjs의 app, components, services 소스와
package.json, README.md. 경로는 모두 저장소리 루트 기준이다.
판정 기준: 포함 = 요청한 세부 항목의 코드 사례가 확인됨,
부분 포함 = 일부만 확인되거나 다른 기술로 유사 기능을 구현함,
미포함 = 해당 기술의 구현이나 의존성이 확인되지 않음.
코드와 문서를 정적으로 확인한 결과이며 실제 실행이나 서버 연동 성공을 검증한 것은 아니다.
주석으로만 작성된 예시는 실행 중인 구현으로 판정하지 않았다.

요약: 포함 6개, 부분 포함 3개, 미포함 4개.

1. React 기초 / React 이해 — 부분 포함
   - React 및 JSX: 포함. 함수형 React 컴포넌트와 JSX 사용.
     근거: frontend\nextjs\app\page.js:12, 21, 53.
   - 개발 환경: 부분 포함. Next.js 개발·빌드·실행 스크립트와 실행 안내가 있다.
     근거: frontend\nextjs\package.json:5, frontend\nextjs\README.md.
   - Vite: 미포함. 이 프로젝트는 Vite가 아닌 Next.js 기반이다.
     근거: frontend\nextjs\package.json:5, 13.
   - React 개념을 체계적으로 설명하는 별도 기초 강의 자료는 확인하지 않았다.

     근거: frontend\nextjs\app\page.js:15, 17, 21,

   - 렌더링 후 작업·API 호출·빈 의존성 배열: 홈에서 목록을 요청한다.
     근거: frontend\nextjs\app\page.js:27.

7. DOM 제어 / useRef — 미포함
   - useRef를 이용한 DOM 접근과 렌더링 간 변수 유지 사례가 확인되지 않았다.

8. 컴포넌트 간 데이터 공유 / Context API — 미포함
   - createContext, Context Provider, useContext 사용이 확인되지 않았다.
   - 부모가 props와 콜백을 전달하는 사례는 있으나 Context API와는 다르다.

9. 재사용 로직 / Custom Hook — 미포함
   - 프로젝트에서 직접 설계하고 사용하는 커스텀 훅이 확인되지 않았다.
   - Next.js의 useRouter, useParams 사용은 프로젝트 자체 커스텀 훅 구현과 구분한다.

11. 라우팅 / React Router — 부분 포함
    - React Router의 BrowserRouter, Routes, Route 및 해당 패키지의
      Link는 사용하지 않는다. package.json에도 의존성이 없다.
    - 대신 Next.js App Router의 파일 기반 경로와 next/link의 Link를 사용한다.
      근거: frontend\nextjs\app\menus\page.js,
      frontend\nextjs\app\menus\new\page.js,
      frontend\nextjs\components\Header.js:7, 16.
    - 동적 라우팅은 Next.js의 [id] 경로와 useParams로 구현한다.
      근거: frontend\nextjs\app\menus\[id]\edit\page.js:12, 25.
    - 따라서 라우팅 개념은 학습할 수 있지만 React Router 자체의
      BrowserRouter, Routes, Route 사용법을 이 코드로 확인할 수는 없다.

12. 전역 상태 관리 / Redux Toolkit — 미포함
    - Redux Toolkit과 React Redux 의존성 및 Store, Slice, Action,
      Reducer, Dispatch, Selector 구현이 확인되지 않았다.

    - API 연동: 메뉴 및 채팅 요청 함수가 있다.
      근거: frontend\nextjs\services\api.js:5, 148.

      공유하지만, Context API나 Redux를 통한 전역 상태 관리는 없다.

교육 보완 방향
--------------
- Vite 기반 React 개발 환경은 별도 예제가 필요하다.
- useRef, Context API, 직접 작성한 Custom Hook, Redux Toolkit은
  각각의 학습 예제나 기능을 추가해야 한다.
- React Router 자체를 가르치려면 Next.js 라우팅과 구분한 별도 예제가 필요하다.
- 실제 CRUD 및 API 연동 동작 여부는 백엔드와 환경 설정을 갖춘 후 별도로 검증해야 한다.
